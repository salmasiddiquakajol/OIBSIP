# OIBSIP – Graphics Design Internship

## Task 1: Posters & Fliers

### 📌 Project Overview

This project was completed as part of the Oasis Infobyte Graphics Design Internship Program.

The task focuses on creating two distinct digital poster designs based on different campaign themes. The designs use visual hierarchy, defined colour palettes, readable typography, custom graphic elements, and clear call-to-action sections.

---

# 🍽️ Poster 01 – Food Promotional Campaign

## Project Title

**Bite Into Happiness**

### Campaign Type
Food Promotional Campaign

### Project Overview

This poster was designed as a promotional advertisement for a fictional food brand. The goal is to attract customers by presenting the featured food product with bold typography, vibrant colours, decorative elements, and a strong call-to-action.

### Main Headline

**BITE INTO HAPPINESS**

### Supporting Message

**Big Flavor In Every Single Bite**

### Call-to-Action

**ORDER NOW**

### Contact Information

**000 1234 567890**

### Design Features

- Bold and eye-catching headline
- Clear visual hierarchy
- High-quality food hero image
- Supporting promotional message
- Strong call-to-action button
- Decorative brush-stroke elements
- Food-related graphic elements
- Clear contact information
- Balanced composition
- Good text contrast and readability

### Colour Palette

- Deep Red
- Golden Yellow
- Green
- White

The colour combination was selected to create a warm, energetic, and appetizing food-promotion style.

# 💧 Poster 02 – Water Awareness Campaign

## Project Title

**Every Drop Counts**

### Campaign Type
Environmental Awareness Campaign

### Project Overview

This poster was designed as an environmental awareness campaign focusing on the importance of water conservation. The design uses a clean and impactful visual concept to encourage people to value and protect water resources.

### Main Headline

**EVERY DROP COUNTS**

### Supporting Message

**Save Water Today. Protect Tomorrow.**

### Call-to-Action

**SAVE WATER**

### Design Features

- Strong environmental awareness message
- Clear visual hierarchy
- Water-themed hero visual
- Nature-related graphic elements
- Clean and readable typography
- Effective colour contrast
- Clear call-to-action
- Minimal and focused composition

### Colour Palette

- Deep Blue
- Aqua
- Green
- White

The colour palette was selected to represent water, nature, freshness, and environmental awareness.
